▮▮▮ WHAT'S IN THE BOX ▮▮▮
  1. R-1

    Registry loader — rejection is the contract

    specodex/vendors/registry.py — VendorFact / VendorProfile Pydantic models reusing SourceCitation from specodex.models.commercial (PR #331). load_vendor_profiles() rejects: uncited facts, citations without url/excerpt, db_inference citations, unknown fact kinds, slug/filename mismatches. slug_for_manufacturer() normalizes DB manufacturer strings ("Mitsubishi Electric" → mitsubishi-electric).

  2. R-2

    validate + verify — the replicability audit

    cli/vendor_facts.py + ./Quickstart vendor-facts validate|verify. validate is the gate (exit 1 on violation). verify re-fetches every cited URL through the SSRF-checked (specodex.url_safety.validate_url), robots-respecting, rate-limited PriceFetcher and re-checks each excerpt verbatim (whitespace-normalized). PDF sources report MANUAL — verify skips PDF text-diffing by design.

  3. R-3

    Frontend compile step

    scripts/gen_vendor_data.py compiles data/vendors/*.json → app/frontend/src/data/vendors.json (committed; drift-gated by TestGenVendorData::test_committed_output_matches_live_data). This is the file the Phase 3 vendor drawer (PR #333) reads.

  4. R-4

    Test coverage

    tests/unit/test_vendor_registry.py — 29 tests: loader accept/reject contract, slug normalization, gen-script shape on tmp fixtures, seeded-profile citation completeness. ./Quickstart verify green on both python and frontend stages.
