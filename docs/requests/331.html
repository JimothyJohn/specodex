Phase 1 of todo/COMMERCIAL.md (design PR #330) — the data contract everything else in the commercial program hangs off. ▮▮▮ WHY ▮▮▮

The commercial program (inferred prices, lead-time estimates, vendor facts) only works if every figure is replicable — a reader must be able to trace any number back to a public source or to the exact set of database comparables and algorithm version that produced it. Without a schema that enforces this, estimates drift into looking like facts. This PR encodes the invariants as Pydantic validators so an uncited figure is unrepresentable, not merely discouraged.

▮▮▮ WHAT CHANGES ▮▮▮
  1. A-1

    SourceCitation — the receipt

    New specodex/models/commercial.py defines SourceCitation: either a public-source citation (URL + retrieval time + verbatim excerpt) or a db_inference citation (comparable product IDs + algorithm version). Validators enforce completeness per kind — a URL citation without an excerpt, or a db_inference citation without its comparables, fails validation.

  2. A-2

    SourcedFigure — the figure with receipts

    SourcedFigure wraps a ValueUnit with a confidence tier, an optional dispersion range, and ≥1 citation. The replicability invariants are validator- enforced: no figure without receipts, no inference without its comparables. The excerpt length is capped so a citation stays a quote, not a scraped page.

  3. B-1

    ProductBase gains estimate fields

    price_estimate and lead_time_estimate land as optional, purely additive fields on ProductBase — every product type inherits them, no migration needed. They are deliberately distinct from msrp: a listed price and an inferred price never share a field, so an estimate can never masquerade as a listed price.

  4. B-2

    Guardrail: LLM exclusion

    Both estimate fields are excluded from the Gemini extraction schema (specodex/models/llm_schema.py). The LLM must never invent commercial figures — estimates enter only through the deterministic inference engine (Phase 2, PR #332), which carries its own citations.

  5. B-3

    Guardrail: quality-gate exclusion

    specodex/quality.py excludes both fields from completeness scoring. Estimates aren't datasheet specs — same treatment as lead_time / availability — so a product's quality score neither rises nor falls with the presence of an inferred figure.

  6. C-1

    Codegen + snapshot refresh

    ./Quickstart gen-types rerun — SourcedFigure / SourceCitation now flow into app/frontend/src/types/generated.ts for the Phase 3 UI (PR #333). All seven schema-compat snapshots under tests/unit/fixtures/schema_snapshots/ refreshed for the additive fields.
